# Security

## Supported versions

Only the latest Oriel release gets fixes. Please update before reporting.

| Version | Supported |
| ------- | --------- |
| 1.1.x   | Yes       |
| 1.0.x   | No        |

## Reporting a vulnerability

Please don't open a public issue or discussion for a security problem. Report it privately instead: on this repository's **Security** tab, click **Report a vulnerability**.

Include what you found, how to reproduce it, and which Oriel and Windows versions you used. You'll get a reply within a week, and credit in the release notes once it's fixed, if you'd like.

## Downloads

Only download Oriel from this repository's [Releases](https://github.com/Niix-x/Oriel-Releases/releases). Copies from anywhere else may have been changed.
